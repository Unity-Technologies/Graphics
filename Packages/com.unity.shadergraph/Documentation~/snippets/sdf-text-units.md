---
title: sdf-text-units
---

The **Outline Dilate**, **Shadow Offset**, and **Shadow Softness** values are fractions of the [**Padding**](xref:uie-font-asset-properties) of the font asset, so they behave the same with any font. A value of `1` is as far as the padding allows. **Dilate** ranges from `-1` to `1`, where `0` is no dilation.
