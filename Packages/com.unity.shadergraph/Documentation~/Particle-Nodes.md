# Particle nodes

Access particle system data, such as per-particle transforms, color, and Texture Sheet Animation coordinates, in the Shader Graph shader that a particle system uses.

| **Topic**                                                       | **Description**                                                                             |
|:-----------------------------------------------------------------|-----------------------------------------------------------------------------------------------|
| [Particle Anim Frame](Particle-Anim-Frame-Node.md)                | Provides the current Texture Sheet Animation frame index. |
| [Particle Color](Particle-Color-Node.md)                         | Outputs the per-particle color. |
| [Particle Flipbook Blending](Particle-Flipbook-Blending-Node.md) | Samples a texture with blending between the current and next Texture Sheet Animation frame. |
| [Particle Texcoords](Particle-Texcoords-Node.md)                 | Provides per-particle Texture Sheet Animation coordinates, with Flipbook and Flipbook Blending modes. |
| [Particle Transforms](Particle-Transforms-Node.md)               | Transforms a mesh particle's position, normal, and tangent to Object (system) space. |
